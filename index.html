编码知识

看懂编码，选对版本

// 01 视频编码
H.264 vs H.265

H.264 兼容性广，H.265 体积更小画质相当，下载优先选 H.265 节省空间。

// 02 分辨率
720P / 1080P / 4K

分辨率越高细节越丰富，小屏设备 1080P 已足够，大屏电视推荐 4K 版本。

// 03 音频规格
AC3 / DTS / AAC

环绕声规格决定听觉体验，家庭影院选 AC3/DTS，移动端 AAC 足够清晰。

// 04 封装格式
MP4 / MKV

MP4 兼容性好适合手机，MKV 支持多音轨多字幕，影音发烧友首选。

// 05 字幕选择
内封 vs 外挂

内封字幕省心即开即看，外挂字幕方便切换语言与样式，可按需选择。

// 06 下载建议
怎么选版本

先看编码再看分辨率，优先选择体积适中、编码先进、音轨完整的版本。
